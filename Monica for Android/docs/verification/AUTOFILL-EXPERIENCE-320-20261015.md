# 自动填充渐进升级：表单用途、保存与连续登录

2026-10-15；普通版和 F-Droid 1.0.320 未发布。继浏览器提示与表单范围阶段之后，本次完成剩余三阶段的实现及下述验证。版本号、版本代码和已发布历史不变。

## 行为与范围

- 保留既有系统自动填充、键盘内联建议、手动选择、无障碍补充和身份验证链路。在选定表单范围内，用有界的静态提示识别登录、账号步骤、密码步骤、注册、改密、重置及验证码；输入的凭据不参与用途推断。
- 已保存密码不会填进新密码或确认框，包括直接建议、验证返回与手动选择的兜底路径。生成密码优先只填新密码和确认框；修复建议 Activity 以新任务启动而使 Android 提前取消认证返回值的问题。
- SaveInfo 优先要求新密码及确认值；保存实际新密码，不退回旧密码，不接受空白或冲突的确认值。尊重保存开关与兼容模式。账号步骤使用 Android 的延迟保存，最多检查八份系统提供的相关上下文，要求应用、协议及主机一致。
- 保存时按精确账号和网站主机／原生应用匹配候选，排除归档、删除、非密码和归属冲突条目。先验证身份，再提供“更新已有条目／另存为新条目”，交给原编辑器确认保存。只替换选中记录的密码，复用存储、历史、分组与同步逻辑。
- 对连续登录使用主要目标标识，避免浏览器包名覆盖网站身份；限制最近交互有效期。新请求的来源、字段、捕获值、候选或保存偏好变化时，重新建立选择器状态。
- 结构缓存最多 32 个目标，每个最多 64 个字段，15 秒过期，清除字段值，只在原字段 ID 仍存在时使用。锁定、熄屏、服务销毁清理；旧请求不能替换新缓存。建议缓存核对当前记录并随数据库变化失效。
- 使用单调时钟记录耗时，请求设置 4.5 秒协作取消时限，遍历与构建过程检查取消。账号步骤不解密用不到的密码，响应构建复用已有设置快照。新增诊断只记录阶段、数量和耗时，不记录凭据。
- 保存编辑页复用原生组件；独立放置“不再保存”操作。为 Material 3 扩展保存按钮补全图标的无障碍描述。可编辑 M3E Canvas 草图及实机截图仅留本地，未入库。

## 验证结果

| 检查 | 普通版 | F-Droid |
| --- | --- | --- |

使用公共 `Monica_Issue136_API_32`、x86_64、独立用户 10。安装前后核对应用和测试 APK 的 SHA-256。各轮恢复系统自动填充、输入法、无障碍、屏幕超时及应用测试偏好，清理本轮合成记录和附件。最终返回原用户并停止本任务启动的虚拟机，保留 AVD 配置与数据盘。

主机回归包含 API 29／34 的结构、用途、角色、SaveInfo、回调和生成器映射；同时覆盖账号上下文的跨来源／显式空账号拒绝、过期和替换 ID 缓存、请求取消、会话授权、选择器复用条件，以及既有兼容性保护。两版用例数差异来自已有 AccessibilityServiceRestartTest 的平台分支。

设备验证包括：

1. 注册表单仅填账号，旧密码不进入新密码框；改密时保留旧密码，生成值只进入新密码及确认框；锁定后验证返回仍遵守字段角色。
2. 真实 AutofillManager 提交、Android 保存提示、保存确认、共享编辑器及数据库读取：保存新密码；两步登录恢复第一步账号。
3. 更新原条目后保留另一密码、备注和应用绑定；创建真实加密的 1024 字节二进制附件，验证保存后元数据及解密字节均不变。
4. 更新项目中第二个账号，保留第一账号密码、两个账号的分组／密码标识、自定义字段、文件夹、收藏和历史旧密码。
5. 锁定保存必须验证，取消不写入；验证失败后可重试；选择器重建、返回原页面与取消后重试。
6. 原生、中文非标准提示、登录旁的帮助 WebView、分步登录、WebView input/change 事件、多个 HTML 表单、computed 提示、键盘内联建议，以及替换密码节点的动态 WebView。
7. 其他网站不得复用授权；手动锁定及熄屏撤销授权；关闭验证保留后下一步重新验证；服务重建保持有效授权；等待真实两分钟后授权到期。
8. 小保险库、大保险库和长表单的实际点选填充及阶段耗时。

普通版首轮把生命周期负例和保存正例放在同一次 instrumentation 进程中，27 项中有 4 项进入验证页而未达到测试预期。四项独立进程重跑均通过；保留这个失败记录，不将其描述为整组一次通过。F-Droid 将 20 项主要流程与 7 项生命周期用例分开运行，两组全部通过。最后的选择器参数复用修正通过新增主机用例，并在两版重跑验证返回、取消重试和选择器重建场景；F-Droid 同轮重测性能。另纠正测试中的系统按钮大小写匹配、锁屏环境检查，以及 Material 3 按钮语义问题。

## 安全检查与参考边界

人工检查覆盖：新旧密码分离、候选归属、显式确认更新、验证前不枚举账号、主会话与临时授权隔离、跨网站拒绝、缓存值剔除／有效期、取消与重复返回，以及日志内容。没有新增权限、联网服务、遥测上传或依赖；普通版与 F-Droid 本次修改文件内容相同，保留各自原有功能差异。

参考本地 1Password 静态分析的页面语义、浏览器提示、流程分层和返回行为，独立实现。没有复制反编译实现、运行所提供的 APK／脚本、移植闭源 Rust 核心或站点库。静态报告中关于云端热更新、性能优势和自动提交的推测不作为已证实事实；本次也没有实现自动提交表单。

实际设备覆盖为 API 32；API 29／34 为主机模拟测试。WebView 与合成浏览器提示不是所有浏览器、网站、OEM 系统和自绘控件的验收。4.5 秒是可协作取消的时限，不保证强制中断系统 Binder 或其他不可取消的同步调用。

## 集成候选

两份旧集成候选同步了本次自动填充源码、适用测试、版本说明，保留原有实验改动。它们尚无当前主线的独立账号项目编辑器和保留解锁设置，因此沿用各自旧编辑器的单记录更新，并在锁定保存时要求验证；没有硬搬缺失的项目模块。

两份候选的编译检查均仍被既存 PasskeyPortability／PasskeyPortabilityCache／PasskeyPortabilityInfo 对缺失 `backupEligible`、`backupState` 的引用阻断，本次新增自动填充依赖错误已消除。候选不计入上表的构建或设备通过结果。正式 F-Droid 工作树独立构建；原始 F-Droid 检出中的 174 项未提交改动另行保留，合并前后核对既有文件散列。
