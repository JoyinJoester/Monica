# Issue 167：网址字段中的 Android 裸包名匹配

2026-10-20；普通版与 F-Droid，1.0.321 未发布。

## 原因与修复

截图中的目标应用为 `com.cn21.ecloud`。原匹配器只从网址字段提取 `androidapp://` 或 `android-app://` 应用绑定，把没有协议前缀的包名留给网址主机解析，因此原生应用请求无法通过该字段命中包名。新增 `strict mode should match bare package name stored in website` 单测在修复前失败，修复后通过。

现在从网址列表中提取由至少三个合法标识段组成的裸包名，作为额外的精确应用匹配信号。原有普通网址、显式应用 URI、直接应用绑定和多绑定解析继续工作。不会将带 `https://`、路径的值或不同包名当成相同应用；没有网页域名的浏览器请求仍不能通过包名猜测账号。保持现有来源筛选、匹配开关和网页域名优先策略。
