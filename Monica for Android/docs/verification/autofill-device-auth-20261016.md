# 自动填充系统验证回归 · 1.0.320

2026-10-16。复用公共 AVD Monica_Issue136_API_32，API 32、x86_64、专用用户 10；仅合成凭据。

## 行为

- 匹配建议先显示；选中账号后复用 BiometricAuthHelper 的系统指纹／锁屏验证，不再次选择账号。
- 无匹配或进入完整选择页时只在入口验证一次；关闭快捷填充验证也不跳过完整选择页验证。
- 验证前候选 Dataset 不携带密码值；系统验证取消或失败不返回填充值。
- 原有可选 120 秒授权仍限制于同应用、同标准化域名；原生 androidapp URI 不再被误记为网页域名。锁屏、手动锁定与关闭保留开关会撤销授权。
- 密钥不可用时不绕过保护：提示先在主应用恢复一次密钥访问。自动填充不会授予主应用或输入法会话。

## 验证

- 普通版及 F-Droid：自动填充单元测试、Debug APK、AndroidTest APK 编译通过。Robolectric 包含 API 29 和 34 的 Dataset／PendingIntent 回归。
- 普通版 14 个实际系统场景通过：锁定与已解锁主应用的选中验证；完整选择页（快捷验证开／关）；取消与重试；错误 PIN 与重试；跨域重新验证；两步登录／服务重绑定；手动锁定；锁屏；开关关闭后重新开启；不保留授权；Picker 重建；Dataset 授权；错误指纹后正确指纹一次完成填充。
- 最初的取消测试只隐藏了系统 PIN 键盘，修正驱动为真正关闭验证界面；锁屏测试改为等待 PIN 键盘再输入。最终这三项复测通过。
- 指纹由已录入的模拟器传感器 ID 1 验证；先触发未录入的 ID 2，确认系统拒绝且不授予授权，再触发 ID 1 返回原表单并检查用户名／密码。
