# 彩蛋语言备份

2026-10-12：喵喵语（zh-NY）、芝士雪豹语（zh-XB）及雪豹桌面图标从应用中移除。

本目录按原仓库相对路径保存语言 XML、头像原图、图标包装 XML，以及原有专用测试、生成脚本和说明（如该仓库原有）。`entry-labels/` 保存从公共资源文件中移除的语言名称和图标提示。`SHA256.json` 记录完整迁移文件的校验值；目录内的 Git 属性禁用换行转换，跨平台检出时保留原始字节。

备份位于 Android 源码集之外，不参与编译和安装包打包。脚本和测试仅作历史存档，不应在此位置直接运行。恢复功能时须重新接入语言枚举、设置、启动图标和测试。

旧设置中的 NYA / SNOW_LEOPARD 自动恢复为简体中文。旧启动别名仅保留普通图标作为升级兼容入口，随后由现有升级修复机制关闭，避免已启用旧别名的用户失去桌面入口。
