# 附近设备同步方向

默认双向同步，沿用已有配对、定时设置和保险库内容。方向是本机设置，适用于本机所有已配对设备，不会用对方的选择覆盖本机设置。

- 双向：允许发送本机内容，也允许保存对方内容。
- 仅发送：允许发送，不保存对方保险库内容。
- 仅接收：允许接收，不准备或传输本机的保险库导出与附件，也不发送内容解密密钥。

一次传输取双方权限的交集。一端仅发送、另一端双向或仅接收时，内容只从发送端流向接收端；仅接收与双向组合也形成单向传输。双方都仅发送或都仅接收时明确提示方向不匹配。

方向在已加密、已验证身份的连接内确认。协议仍为 2，保险库内容版本仍为 2。缺少方向能力字段的旧客户端继续支持双向；单向与旧客户端组合必须报“不支持单向”，并在传输保险库文件与附件之前失败。

切换方向先中止旧传输，再保存新设置、废弃旧导出缓存并请求重新同步。方向设置与保险库内容、共享频率设置分开保存，重启后保持选择。旧设置缺少方向字段时默认双向，未知方向值必须拒绝读取，不能默默启用双向。

仅发送的会话无需等待接收侧编辑锁，也不调用本机保险库应用更新。双方仍确认传输与保存结果；只有成功确认后才记录同步时间。仅接收的等待连接循环不扫描或导出本机内容。

连接角色与内容方向相互独立：任一端都可能被选为监听端。仅接收端等待连接时同样不需要本机发送包，允许在空本地数据库上接收首次同步；发送和双向监听端仍须提供有效发送包。无需清空数据、重新配对或改成双向。

手动同步遇到对端更新监听地址等临时连接失败时，会在原有请求超时内重新发现并重试；用户取消、应用锁定或进入后台仍会停止。身份验证拒绝、方向冲突和内容保存失败不会按临时连接错误重试。

配对保存身份，首次内容同步另行完成。设备显示“已配对 · 首次同步未完成”或具体失败状态，最近成功时间只来自成功完成的内容同步。准备完成或失败后清除准备进度，避免 851/851 停留为正在准备。

与 Android 当前主分支整合后，保留通行密钥的 WebAuthn 备份资格和备份状态。资格属于凭据身份，已有凭据不能改变资格；未知字段不能当成成功备份。元数据更新缺少这些字段时保留原值，非法资格/状态组合必须拒绝。Android Room 导入导出也保留这些字段。

Windows 通过新增可空数据库列保存这些标志，实际认证签名采用该凭据的标志。旧 Windows 凭据缺少标志时沿用原认证行为；旧原生记录可从已保存的同步元数据恢复已知值。已缓存的原生投影也执行恢复并持久化；Android 投影从匹配到的原凭据保留标志，包括仅存在于 Room 的原凭据。元数据更新先验证公钥身份，再保留原私钥及本机状态。

验证覆盖真实加密连接中的 16 种方向和旧客户端组合，核对禁止方向没有保险库文件或附件落盘；覆盖设置加密存储与旧格式迁移、切换方向取消旧连接、仅接收无需本机导出、仅发送不调用接收保存以及编辑锁。保留原有通行密钥、公钥格式、受保护私钥和全量内容回归。实机分身与 Wi-Fi 联调不能由这些本地测试代替。
