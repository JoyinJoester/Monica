# Wallet templates — discussion #169

Date: 2026-10-21. Development version: 1.0.321 (unreleased).

## Behavior

The wallet create menu now offers bank cards, documents, billing addresses, membership cards, rewards cards and travel passes. Membership and rewards templates include the issuer, membership number, holder, tier and website; rewards add points balance and points expiry. Travel passes include carrier, ticket/booking reference, passenger, flight/service number, origin, destination, departure/arrival text with time zones, terminal/platform, gate, seat and class.

The three new templates have separate saved drafts, dedicated list filters, searchable extra fields, copyable non-empty details and ordinary in-place editing. They reuse card artwork, notes and attachments. Wallet creation uses the common template menu on compact and wide layouts.

## Storage and compatibility

Templates extend the existing portable document payload with `walletTemplate` and string-valued `walletFields`. Existing document types, database schemas and item-kind values remain compatible. Unedited extra map keys survive editing, and embedded-document patches retain template data.

Bitwarden carries template metadata and the membership/ticket number in encrypted reserved fields. A fresh download restores the template without exposing internal extension fields as user custom fields. Pass numbers are not uploaded as SSNs, and wallet passes are excluded from identity-document autofill candidates.

This implements manually maintained templates; live airline integration and Apple/Google wallet pass-file import are outside this change. Bitwarden verification uses encrypted requests and fresh downloads against a local test server, not a production account. Wi-Fi transport was not retested in this change; the existing document payload and item kind are reused.
