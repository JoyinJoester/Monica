# 喵喵语映射表（Nya Metaphor Map）

> 叮咚——猫妈妈 Monica 开门啦喵！
> 每条密码都是一只猫猫，被她一趟一趟叼回窝里藏好喵。
> 名字（账号）您来取，暗号（密码）只有您和猫妈妈知道，外人学不来喵。
> 窝里暖暖的，猫猫们在纸箱和柜顶之间打盹，云朵那边还有亲戚家可以寄住喵。

这就是喵喵语的全部设定。写新文案时先想"这件事在猫妈妈的世界里是什么"，
再从下面的表里拿词。猫味不能替换功能语义——文案先得让人会用，再让人会笑。

喵喵语（values-zh-rNY）的文案分两层：

- **自动变换**：`generate_nya_strings.py` 对 values-zh 做机械处理（句末标点前插"喵"、
  标签类补尾喵、词汇规范替换），不改变其余用词。未翻译的条目使用普通中文回退。
- **人工润色**：`nya_overrides.txt` 逐条重写。本表约束的是这一层：
  按同一套世界观选词，让全包像同一只猫在说话；无需每句都带“喵”。

底栏短标签（`nav_*_short`）沿用 `values-zh` 的简短中文，生成器也不覆盖这些条目。

对外名称：应用内语言名叫「喵喵语」（`language_nya` / `qs_lang_nya`），
README 署名「黑羽川」，指同一种语言。

## 1. 本体对照表（世界观）

| 猫世界 | 本义 | 实例（key=文案） |
|---|---|---|
| 猫妈妈 Monica | 应用本体与界面说话声，自称"人家" | `settings_about=关于人家喵`、`support_author=给人家投喂小鱼干喵` |
| 猫猫 | 密码条目（每条是一只，量词"只"） | `add=添一只喵`、`autofill_detected_passwords=嗅到 %1$d 只密码喵` |
| 名字 | 账号/用户名（用来认哪只是哪只） | `common_account_username_hint=你的名字喵` |
| 暗号 | 密码（只有猫妈妈和您知道） | `setup_master_password=给窝配一把主密码喵` |
| 收编的流浪猫猫 | TOTP 验证器 | `totp_migration_import_selected=收编 %1$d 只喵` |
| 爪印 | 通行密钥 | `biometric_subtitle_passkey_create=给 %1$s 配一把通行密钥喵`（界面沿用"通行密钥"叫法） |

两代人，猫猫住妈妈的窝，不住在妈妈肚子里。"Monica 是猫"与"密码是猫猫"
就此不再打架。

## 4. 量词规则

量词是"猫猫=条目"这条映射的主要载体，**润色层必须贯彻**；高曝光的
自动层计数串也已补齐 override，剩余长尾有意豁免（见下方豁免清单）：

| 量词 | 用于 | 例 |
|---|---|---|
| **只** | 密码、条目、记录、验证器——一切"一条密码数据"（猫猫） | `webdav_backup_passwords=密码：%d 只喵` |
| 张 | 银行卡、卡片、二维码、图片 | `wallet_stack_selected_count=已经叼中 %1$d 张卡片喵` |
| 本 | 证件、笔记 | `note_picker_title=挑一本笔记喵` |
| 个 | 数据库、应用、字段、包名、账号、文件夹 | `vault_overview_locked_excluded=还有 %1$d 个睡着的数据库没算进来喵` |
| 条 | 账单流水、支付信息（流水语义） | `import_data_success_alipay=叼回来 %d 条支付宝账单喵` |
| 根 | 爬柱（导航项） | `只剩一根爬柱时收起猫爬架喵` |
| 把 | 通行密钥（钥匙） | `biometric_subtitle_passkey_create=给 %1$s 配一把通行密钥喵` |

边界判定：**账号是猫猫的名字，不是猫猫本身**——`%1$d 个账号` 保持"个"，
只有把整条密码数据当对象提起时才用"只"。

豁免清单（自动层遗留的"个/条"不追）："这个/每个密码"这类指示用法是语法
不是计数；mdbx 内部历史记录（"条记录"照用）；永久删除确认框（见 §5）。

## 5. 生成器词汇规范

`generate_nya_strings.py` 的 `REPLACEMENTS` 表对**所有最终输出**统一替换
（自动变换和 override 文本都过这一层），新增文案自动继承：

- `你` → `您`：人称统一为敬称。润色时写"你"就行，不用操心；
  README_Nya 保留"你"的自家风格，不受生成器管。
- `回收站` → `纸箱`：世界观规定回收站是装猫猫的纸箱。
  永久删除确认框不玩梗：纸箱照用、喵照插，但不用猫猫/打盹这类萌词。

## 6. 风格规则

1. 声口是**元气猫猫系**：叠词（猫猫/暖暖/一趟趟）、场景化短句，
   参照 NPatch 的活泼劲（塞进窝里/踩奶），但术语密度别超标。
2. 引号用「」；禁用字符 `< > & ' "`——生成器会整条拒绝违规 override。
3. 占位符（`%1$s`、`%d`）与品牌词（Monica/KeePass/Bitwarden/Steam/WebDAV/MDBX）原样保留。
4. **语义可懂度 > 猫味**：功能入口保留原词（`bottom_nav_settings=设置喵`，
   刻意不写成"铲屎指南"）。猫味优先花在状态、反馈、结果类文案上，
   而不是导航和操作入口。
5. 喵的落点：句末标点（。！？…与半角 ! ?）**前**（`要移除这个数据库喵？`）；
   无标点标签补尾喵（`存好喵`）。手写时照此放置，生成器检测到喵就不会再补。
   半角标点优先写全角，写漏了生成器也会正确插喵。
6. 哈气只用于"轻挫败"（网络、鉴权、格式问题）；涉及数据安全后果的
   告警（覆盖本地、永久删除确认）保持严肃直白。

## 8. 已弃用

- **猫砂盆／铲屎**：世界观定为"猫妈妈的孩子"后，孩子不进砂盆，
  埋猫意象全部退役。回收站改由纸箱承担，清空回收站 = 纸箱大扫除。
- **罐罐**：弃用。"储物罐"已含"罐"，再用罐罐指代别的东西会撞车。
- **崽**：不用这个字，孩子一律叫"猫猫／小猫"。
- **肉垫指输入框**：NPatch 里"揣入肉垫"=填入，本项目肉垫专指剪贴板，别混用。
