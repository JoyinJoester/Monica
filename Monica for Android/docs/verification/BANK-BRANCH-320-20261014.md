# Bank branch field verification — 1.0.320

Issue: https://github.com/Monica-Pass/Monica/issues/165

## Behavior

Bank cards expose Bank branch (开户行) immediately below Bank Name in the existing
basic-information form. The shared editor also serves embedded cards. The field
supports common-value suggestions, editing, clearing, detail copying and card
search. Bank name, branch code and existing custom fields remain independent.

`BankCardData.bankBranch` defaults to an empty string for older JSON. Standard
serialization preserves it in backups and native MDBX payloads. Legacy card
parsing and embedded payment projection retain it. KeePass stores it as
`Bank Branch`; Bitwarden encrypts it as a named card field and restores it without
also presenting it as a generic custom field. Local edit history includes it.

## Validation

- Ordinary edition: 42 host tests, zero failures/errors/skips, across BankBranch,
  CardWalletDataCodec, CommonFieldSuggestions, WalletListItem, EmbeddedWalletContent
  and PasswordWalletProjection suites.
- Ordinary edition: 5 instrumentation tests on the shared API 32 x86_64 AVD,
  zero failures, 30.131 seconds. Real Compose editors create, save, reopen, change
  and clear the field. The detail action copies its complete value. Native MDBX
  and KeePass files are reopened after saves and title edits. Real Bitwarden
  upload/import processors exchange encrypted synthetic fields through a loopback
  MockWebServer, checking independent bank name/code and existing custom values.
- Both editions build app and instrumentation APKs from source with
  `-PincludeX86TestAbi`. F-Droid passed the same 42 host tests and 5 device
  tests (17.681 seconds), with zero failures/errors/skips. Both native renders
  were inspected. The task-started public emulator was stopped afterward.
- Version configuration, bilingual next-version notes, fastlane 27 size limits,
  resource XML and `git diff --check` were validated. Ordinary versionCode remains
  12; F-Droid advances to 27. Development version is 1.0.320. Existing 1.0.319
  notes were archived unchanged; published F-Droid 1.0.318 and fastlane 25/26
  remain intact. No release or tag was created.

The M3E Canvas draft was rendered locally and checked by selecting a field,
editing its label, exporting JSON and reopening the saved edit. An initial draft
omitted required null icon values and fell back to the default example; the draft
was corrected. Coordinates were corrected to separate its two frames. The final
native editor rendering was inspected. Draft JSON, links and screenshots remain
local under the ignored design directory and are not committed.

The Bitwarden test uses a synthetic local service, not a live Bitwarden account.
